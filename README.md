# AlgoRoute

## Intelligent Machine Learning Strategy Recommendation Engine

**AlgoRoute** is an intelligent meta-learning based system that analyzes dataset characteristics and recommends optimal machine learning algorithm strategies for tabular datasets.

---

## 🚀 Key System Features

- **21 Dataset Meta-Features**: Extracted statistical, structural, entropy, and landmarker probe characteristics.
- **Hybrid Meta-Router**: Machine learning router trained across OpenML benchmark datasets to predict model F1 scores.
- **Explainable Recommendation Engine**: Evidence-based scientific explanations justifying Top-1 model recommendations.
- **Local Data Privacy**: 100% in-memory processing guarantees that user datasets are never saved to disk or uploaded to external cloud AI services.
- **Dataset Health & Suitability Analysis**: Automated dataset quality indicators (sample size, class imbalance, missingness, feature density).
