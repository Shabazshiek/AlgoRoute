Problem Statement & Motivation

The Challenge of Algorithm Selection

⚠️ The "No Free Lunch" Dilemma

No single machine learning algorithm performs best across all tabular datasets. An algorithm that excels on numeric data may fail on skewed or imbalanced data.

⏳ Compute & Time Waste

Data scientists typically perform brute-force trial-and-error model training across multiple algorithms, taking hours and consuming high compute power.

🎯 The Core Question Addressed by AlgoRoute

"Can we extract the structural and statistical fingerprint of a dataset in < 3 seconds to predict the best ML algorithm without training models on it first?"

Project Objectives

System Goals & Deliverables

⚡ Instant Meta-Routing

Analyze tabular datasets in < 3 seconds by extracting a 21-dimensional Dataset DNA.

🧠 Meta-Learning Model

Predict expected F1 scores and rank 6 candidate classification algorithms based on OpenML benchmarks.

🔍 Explainable AI (XAI)

Generate human-readable "Why This Strategy?" justifications for transparency.

🏥 Dataset Health Analyzer

Detect small sample sizes, extreme class imbalance, and high missingness automatically.

🔒 100% In-Memory Local Privacy

Process uploaded CSVs strictly in-memory without persistent disk storage or external cloud APIs.

Theoretical Foundation

Meta-Learning: "Learning to Learn"

🔄 Conventional ML vs. Meta-Learning
Conventional ML

Learns patterns within a single specific dataset to predict target labels $y$ from feature vector $X$.

Meta-Learning (AlgoRoute)

Learns patterns across multiple historical datasets to predict algorithm performance from dataset characteristics.

Historical OpenML Datasets → Meta-Features + F1 Scores → Meta-Learning Router → Instant Recommendation
Dataset DNA

The 21 Dataset Meta-Features

Category Extracted Meta-Features Purpose / Significance
Structural Rows, Columns, Instance-to-Feature Ratio, Numeric & Categorical Ratios, Missing Values Rate Quantifies dataset scale, density, and basic shape
Target / Class Class Count, Majority Class %, Class Imbalance Ratio Detects target distribution skewness & imbalance
Statistical Mean/Std Skewness, Mean/Std Kurtosis, Mean Absolute Feature Correlation Captures non-linearity, distribution tails & multi-collinearity
Information-Theoretic Class Entropy, Normalized Class Entropy Measures class uncertainty & information content
Landmarking Probes Decision Stump F1 Score, Naive Bayes F1 Score Quick micro-tests gauging baseline dataset difficulty
Candidate Portfolio

6 Candidate ML Algorithms

🌲 Random Forest

Bagging ensemble of decision trees. Robust against non-linear interactions & noise.

⚡ Gradient Boosting

Sequential boosting ensemble. High predictive power for structured tabular data.

📈 Logistic Regression

Linear probabilistic classifier. Fast baseline for linearly separable feature spaces.

📍 K-Nearest Neighbors

Distance-based non-parametric learner. Effective for localized decision boundaries.

🌿 Decision Tree

Interpretable rule-based learner. Fast inference and clear decision paths.

📊 Gaussian Naive Bayes

Probabilistic generative model assuming independent continuous features.

Architecture

System Workflow & Pipeline

⚙️ Offline Training Pipeline
  • Fetch historical benchmark datasets from OpenML
  • Extract 21 meta-features for each benchmark dataset
  • Evaluate candidate algorithms using 5-fold cross-validation
  • Construct Meta-Dataset & train Meta-Router model
  • Serialize trained artifact (`meta_router_model.joblib`)
🚀 Online Inference Pipeline (< 3s)
  • User uploads new CSV dataset via Web Dashboard
  • Extract 21 meta-features strictly in-memory
  • Run Dataset Health Analyzer & generate warnings
  • Pass Meta-Features into loaded Meta-Router model
  • Rank algorithms, predict F1 scores & render XAI explanation
Quality Control

Dataset Health Analysis

🔍 Evaluated Conditions
  • Small Sample Size: Flags datasets with < 50 instances (high variance risk).
  • Severe Class Imbalance: Flags imbalance ratios > 3:1 or 8:1 (SMOTE recommended).
  • High Missingness: Flags missing value rates > 5% or 15%.
  • High Dimensionality: Flags low instance-to-feature ratios (< 5:1).
🚦 Health Status Badges
🟢 HEALTHY / GREEN — Clean, balanced, standard dataset shape.
🟡 REVIEW RECOMMENDED / YELLOW — Minor imbalance or missing values.
🔴 ATTENTION REQUIRED / RED — Extreme imbalance (>8:1) or tiny sample.
Core Prediction Engine

The Meta-Router Model

🤖 Model Implementation

Built using a hybrid multi-output ensemble architecture (RandomForestRegressor) trained on extracted meta-feature fingerprints and historical cross-validated F1 scores.

Serialized Artifact data/processed/meta_router_model.joblib
📊 Output Metrics
  • Predicted F1 Scores: Estimated F1 score for all 6 candidate algorithms.
  • Algorithm Ranking: Ordered ranking from Rank #1 (Top Strategy) to Rank #6.
  • Recommendation Score: Relative strength index scaled from 65.0 to 98.5.
Explainable AI

"Why This Strategy?" Engine

💡 Human-Readable Justification

Converts numerical meta-features and router predictions into clear natural language explanations to build user trust.

🔑 Supporting Evidence Factors
  • Primary prediction margin over runner-up strategy
  • Dataset instance-to-feature density suitability
  • Landmarking probe signals (Decision Stump & Naive Bayes F1)
  • Class entropy and non-linear interaction patterns
📋 Algorithm Suitability Matrix

Provides contextual strengths for all alternative strategies so data scientists understand alternative tradeoffs before model training.
